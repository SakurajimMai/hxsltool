# HXSL 建筑 AI 工作台

状态：用户已确认常规工作台方案并要求完成。2026-09-08 开始实施。禁止引入 infinite-canvas 代码、依赖或无限画布交互。

## 目标与已确认范围

在已有 Next.js/React/TypeScript、SQLite 持久卷和 Node Worker 架构上增加建筑图像生成产品。现有 82 个文件工具和 15 种语言保持可用、免公众账号，不恢复开放转换 API/CLI。

- 文字、草图或参考图片输入，生成 2D、2.5D、3D 风格的建筑户型概念图像。
- 常规工作台：桌面左侧参数、右侧结果，手机单列；结果对比、下载、继续修改、历史及删除。
- Google 登录，仅 AI 功能要求用户账号；用户与管理员身份隔离。
- 积分购买/订阅、模型按积分计费；参考 AIHousePlan 套餐结构，价格和额度由后台维护。
- PayPal、Creem、Stripe 支付适配、验签、幂等订单入账、退款/争议状态及对账。不以浏览器支付返回页作为付款证据。
- 后台管理图像供应商、模型与真实能力、全局/风格提示词、积分价格、套餐、用户积分调整、订单、去敏生成异常。
- 管理配置草稿、校验、发布、版本/回滚；供应商秘密只写不读、部署主密钥加密，不输出到浏览器/日志/普通导出。
- 生图走服务端与供应商，不让站点服务器执行 GPU 推理，不把云生图误称本地处理。图片上传前明确用途与外部处理方。

## 能力边界

产物为可独立解码的图像，不是 CAD/BIM 文件、可交互 3D 模型、施工图或结构安全验证。尺寸、房间关系和跨视角一致性需要人工核查。仅建筑设计场景，不增加视频、通用聊天、Agent、插件市场、任意 JS 模板、公众转换 API 或 CLI。

## 验收

1. 后台配置发布后，前台模型、参数、报价与实际任务读取同一版本；旧任务按冻结报价结算。
2. Google 登录处理 state/PKCE/nonce、令牌验证、会话撤销与隔离；未授权不可访问他人资产、订单、历史或积分。
3. 下单不发积分；仅验证后的支付结算事件发放。重复事件、乱序回调、并发购买及退款不多发或错误扣减。
4. 生成前校验输入、余额和并发；先冻结积分，成功结果按有效图片结算，部分成功只收成功份数，明确失败释放，不以网络超时盲目重发供应商请求。
5. 文生图和参考图编辑均通过真实供应商验收；测试替身只用于隔离合同测试，不能代替供应商验收。
6. 已生成图片重新解码核对格式、尺寸；不返回假图。继续处理复用授权资产并再次明确生图费用。
7. 前后台移动端、深浅主题、键盘/焦点、错误状态截图实际审查；15 种语言及 SEO 不倒退。
8. 重启、容器重建、任务恢复、账本与配置备份恢复在隔离环境验证；不删除既有数据或卷。

## 外部配置与发布边界

真实生图供应商、Google OAuth 客户端、三家支付商户密钥及测试产品 ID 需要由站点所有者在受保护配置中提供。不得在对话中索取明文密钥；无配置显示不可用，不假装联调完成。正式 HTTPS/OAuth 回调域、真实收款和 DNS 变更不自动执行。套餐参考数据不是成本已核验或利润保证。
