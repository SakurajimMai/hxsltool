# AI 运营配置导出与草稿导入

此功能在既有后台「建筑 AI → 模型、提示词与套餐 → AI 配置备份与导入」内。沿用 Next/React、管理员会话、配置 schema、SQLite 版本表和发布链路，不创建公开 API 或终端用户 CLI，不新增数据库/服务/依赖。

## 管理员路径

1. 选择「已发布配置」或「已保存草稿」，点击「导出 AI 配置 JSON」。浏览器收到可解析 JSON 文件；未保存的表单内容不包含在内。下载提示只声明发起下载，不冒称已成功落盘。
2. 选择不超过 1,000,000 字节的非空 JSON。存在未保存编辑时先保存或重新读取；导入操作期间锁定同一配置面板，避免晚到响应覆盖继续编辑的内容。
3. 服务端预检结构/大小/参数/硬上限，显示相对当前草稿（没有草稿时相对发布版本）的逐字段差异、相对发布版本的差异数量，以及本机供应商依赖。可展开查看安全文本形式的完整候选配置。
4. 勾选确认后「确认导入为草稿」。原草稿保留在版本历史，导入创建本机新版本；外部 source.version 不成为本机 ID，不改变当前发布版本。
5. 在「发布与版本」复核保存结果，再单独「发布已保存草稿」。沿用现有发布校验/刷新，前台新任务和原始 HTML 使用新发布版本；原订单、任务、冻结报价与文件 TTL 不变。
6. 如需恢复旧配置，使用现有历史版本「重新发布此版本」。回滚新建版本并保留审计，不倒退数据库或清空流水。

发生冲突时不覆盖别人新版本。错误后清除旧预检和确认操作；重新读取最新版本，再预检并确认。导入响应中断可能已经保存，先在「发布与版本」重新读取及查看 `config.import` 记录；不要靠重复导入或发布猜测结果。原版本锁拒绝同一请求再次导入，不会重复创建版本或审计。

## 导出内容与排除项

格式 `kind=hxsl-ai-configuration / archiveVersion=1`，包含导出时间、来源配置版本/草稿或发布状态，以及经过 `validateAiConfig` 白名单重建的配置：

- 全局与 2D/2.5D/3D 建筑运营提示词。
- 模型、已实现 Images 协议、供应商 URL、上游模型名、密钥槽名称、允许参数、整数积分费率。
- 积分套餐、金额/周期/额度及 Stripe/Creem/PayPal 商品 ID。
- 现有允许范围内的并发、批次、保留时间及接受新任务开关。

**不读取或导出**密钥明文/密文、部署主密钥、OAuth 客户端秘密、管理员/用户资料、会话、MFA/恢复码、账本、订单、生成任务/用户提示词、参考图/结果或文件授权。来源操作者与整个版本历史也不包含在 JSON 中。导出不等于完整数据灾难恢复；后者见 [受限数据库备份恢复](backup-restore.md)。

供应商 URL、商品 ID 和运营提示词本身仍可能属于内部业务信息，请妥善保管。不要将真实密钥或用户原文手工填入这些运营文本字段；字段白名单不能辨认被误填为普通文字的秘密。

## 服务端边界

- 仅内部 `/api/admin/ai/config/archive`：GET 导出；POST `preflight` / `import`。逐请求验证管理员身份、同源、15 分钟内重新认证；写请求还要求 CSRF，导入必须明确确认。响应 `no-store` / `noindex, nofollow`，导出为 JSON attachment。
- 流式请求上限 1,002,048 字节（包含外层操作字段）；档案内容另按 UTF-8 序列化上限 1,000,000 字节验证。缺失/伪造 Content-Length 不绕过实际流量上限；复用 30 秒读取超时和 reader 取消释放。
- 不允许不认识的 envelope/source/config/model 字段、任意脚本、协议、危险模板、重复 ID、缺失参数价格、未来版本或超出硬上限的值。导入不是 SQLite/任意文件导入器，不接收任意路径。
- 预检指纹绑定规范化档案全部内容与当前编辑 revision；导入再次验证。指纹是差异确认绑定，**不是备份真实性签名或授权凭证**；鉴权仍由管理员会话负责。
- 依赖检查只查询本地密钥槽/解密能力和部署域名允许列表，不发送模型或支付请求。缺依赖的合法配置可进入草稿，但现有发布入口仍拒绝不完整部署；不通过导入修改部署环境变量。
- 新草稿与 `config.draft` / `config.import` 审计在同一事务提交。审计只记录本地版本、来源版本和指纹，不记模型提示词、上传文件名、导入原文或秘密。
- 不调用发布/cache 刷新。发布和回滚仍通过既有独立操作；商品存在性、商户环境和真实模型能力须在外部联调核查，预检不伪称通过付费服务认证。

## 实证与限制

```bash
pnpm --filter @hxsl/web exec vitest run lib/ai/config-archive.test.ts
pnpm test:ai:archive
pnpm test:ai:operations
pnpm test:backup
```

- 配置服务/匿名 handler 17 项：秘密排除、发布/草稿选择、非法档案、UTF-8 大小、注入/无效参数、预检不写、并发锁/变更指纹、断线重放、缺依赖拒绝发布、独立重开、发布回滚、旧冻结任务/账本/秘密不变。
- `test:ai:archive` 真实本地 Next/HTTP/浏览器/SQLite：认证/CSRF/来源/重新认证、下载后解析、上传预检、键盘确认、草稿隔离、发布改变原始 HTML、回滚、危险输入、并发保存、真实提交后丢弃响应再恢复。没有用浏览器假成功代替写入；只对丢响应使用 `route.fetch` 实际提交后断开观察。
- 最终截图在 `evidence/config-archive/`，6 组流程、9 张截图、无页面脚本错误和外部浏览器请求，组件范围 axe 无违规；不是全站 WCAG 或全部语言验收。桌面 1440、手机 390/320 的表单、双列→单列差异、草稿状态、错误实际审查。
- 第一轮截图发现冲突后仍保留过时确认入口，修复为清除预检；并把通知提高到 14px。补充差异和错误区域截图，截取稳定主题状态，避免以切换过程的颜色当成稳定界面。
- 生产 standalone 校验扩展为新接口权限、HTTPS 导入、重启保留草稿、发布与回滚。最终运行结果以 `evidence/production/standalone-report.json` 和 `validation.md` 为准；单库重启不是容器重建。

此模块不完成尚缺的 AI 13 语言、支付对账/真实商户沙箱、Google/模型外部验收、容器重建或完整文件工具回归。没有发布公网或操作正式数据。
